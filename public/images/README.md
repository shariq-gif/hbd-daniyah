# Drop her photos here 📸

Put your image files in this folder, then reference them in
`src/config/birthday.config.ts` like `"/images/photo1.jpg"`.

Expected by the default config (rename yours to match, or edit the config):

- photo1.jpg … photo5.jpg  → the scrapbook polaroids
- final.jpg                → the very last surprise photo

Tips:
- Any web format works: .jpg, .png, .webp
- Roughly square or portrait photos look best in the polaroids
- Missing photos won't break anything — a pretty pastel placeholder with the
  caption is shown until you add the real ones.
